# Haru character cards

Official character cards of the Haru model, embedded into the app (`src/cards.rs`, `include_str!`).

- Source: <https://github.com/higurashi-ai/Haru/tree/7fe6b7665f8bf035998f401f8cb779fbe53f2751/haru/haru/assets/cards>
- License: Apache-2.0 (see `LICENSE`)
- The files are unchanged copies, one per language (`de`, `en`, `es`, `fr`, `ja`, `ko`, `pt`, `ru`, `zh`).
- Only the preset `chat` is used.
